Drop your audio files here — .mp3, .m4a, .wav, .flac, .ogg, .opus.

Then run start.command (double-click it) and they appear in the player,
in filename order.

Titles are read from each file's own tags. If a file has none, the filename
is used, and a name like "Nils Frahm - Says.mp3" is split into artist and
title automatically.
